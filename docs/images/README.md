# README 展示图片

本目录用于项目首页展示，不包含原站截图或私人运行数据。

| 文件 | 内容 | 类型 |
| --- | --- | --- |
| `hero.svg` | Private Home 封面与抽象工作区概念图 | 原创 SVG 示意图 |
| `workflow.svg` | 聊天与链接辅助分类共用的整理流程 | 原创 SVG 流程图 |
| `architecture.svg` | 应用组成与数据访问边界 | 原创 SVG 结构图 |
| `overview.png` | 关注网站工作区 | 公开源码实际界面截图 |
| `papers.png` | 论文库书目信息与摘要 | 公开源码实际界面截图 |
| `memo.png` | 图文备忘录编辑 | 公开源码实际界面截图 |
| `tasks.png` | 待办事项三列看板 | 公开源码实际界面截图 |
| `appearance.png` | 面板颜色、透明度与空闲特效设置 | 公开源码实际界面截图 |

截图在独立演示数据目录中制作，没有连接原站数据库，没有调用真实模型服务。管理员账号、会话与配置不包含在图片中，也不在本目录分发。备忘录中的阅读计划、阅读流程图与待办内容均为专门编写的演示素材。

论文展示使用公开书目信息：[CLIP，PMLR 139](https://proceedings.mlr.press/v139/radford21a.html)、[BLIP-2，PMLR 202](https://proceedings.mlr.press/v202/li23q.html)。它们由人工录入演示环境；未填写的指标保持“未核实”，不将截图解释为 AI 导入或指标查询的测试证据。

图片属于文档展示资产，修改它们不需要修改应用运行配置。SVG 中的示意界面不代表额外实现的产品功能；实际功能以源码与运行界面为准。
