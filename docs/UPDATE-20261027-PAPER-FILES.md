# 论文文件与论文名导入

论文库页面只保留“新增论文”入口。窗口内“AI 识别整理”执行检索或分析，与打开窗口是不同操作。

## 输入方式

- DOI、arXiv 与普通论文网页：按原流程读取可用内容，再生成草稿。
- 论文名：从 Crossref 与 arXiv 检索候选，先核对标题、作者和年份并选择一篇，再导入。不会自动保存第一条搜索结果；无匹配时可补充 DOI、文件或摘要。
- 论文名检索限定论文与预印本等文献类型，排除数据集记录，并优先显示标题一致的候选；相近匹配会明确标注，避免将推荐或点评当成原论文。
- PDF：在浏览器内通过固定版本 Mozilla PDF.js 解析，单个文件最大 20 MB、最多 300 页；提取前 12 页、最多 50000 字符。文字层不足时尝试将前 3 页转换为图片，交由现有视觉模型分析。
- DOCX：读取正文并限制解压后的 XML 大小，不执行宏或文档脚本。
- TXT、Markdown、BibTeX、RIS、EndNote ENW、CSL JSON：读取 UTF-8 文本或文献条目。文献文件每次只导入一篇，多条需拆分；没有摘要的书目不会凭标题生成贡献摘要。
- 继续支持截图选择、粘贴，以及将文件拖入导入区域。

## 保存与隐私

原始文档在浏览器内解析，不上传为公开附件。点击 AI 后，提取的文字或转换出的页面图片会发送到你配置的模型。保存时记录书目信息、摘要、文件名与 SHA-256，用于识别重复导入；不保存原文件二进制。

没有 DOI 或原文网址的文件也能保存。没有原文地址的论文标题不会链接到虚构网页；同一文件重复导入时提示应用到已有记录。

管理员可新增、导入和修改，读者只读。所有草稿仍需显式保存，失败时保留此前输入；解析或导入期间修改内容不会被迟到的结果覆盖。

## 边界

- 加密 PDF/DOCX 请先解密，旧 DOC 请先转成 PDF 或 DOCX。不支持任意文件扩展名，也不提供原文件在线下载。
- 扫描件受清晰度、页面编码和视觉模型能力影响，只处理前几页；复杂图片编码或损坏文档可能需要改用截图。
- 论文名检索先检索 Crossref/arXiv 候选，再按标题和作者核验正式记录。候选仍需管理员确认。
- 原有 SCI/CCF/影响因子的年度、证据与待核实规则不变。

## 配置保护

### 夸克 PDF 兼容修复

PDF.js 已切换为同版本 6.4.299 的官方 generic-legacy 构建，页面与 Worker 都包含兼容补丁。解析资源 URL 使用新的 legacy1 缓存标记，刷新后会重新获取兼容资源。此修复针对夸克中缺少 Map/WeakMap.getOrInsertComputed 导致 PDF 渲染失败的情况；不更改文件大小、页数、权限或保存规则。

### 正式出版出处核验

导入 arXiv 链接、PDF/文献文件或论文标题后，使用同一正式出处查询流程：精确匹配标题和作者，查询 Crossref 正式出版记录、DBLP 指向的原始出版页面，以及 PMLR 官方论文集目录。PMLR 目录查询按已提取年份筛选，最多检查八卷，避免无界抓取；查询结果及目录只在进程内短暂缓存。

以 CLIP 为例，正式记录应来自 https://proceedings.mlr.press/v139/radford21a.html ，出版类型为会议、会议为 International Conference on Machine Learning、出版年为 2021，而非仅根据 arXiv 链接认定预印本。正式页面的作者、会议和年份优先于 AI 推断。

该查询不能保证覆盖所有出版社或绕过验证、付费墙和接口限额。未找到时提示“未检索到可确认的正式出版记录，不代表尚未发表”，保留现有资料，并允许粘贴正式论文集链接重试；不会凭模型记忆补齐正式出处或期刊指标。旧记录不会后台批量修改：管理员需重新整理并确认保存。

未增加或修改 npm 依赖配置、锁文件、环境文件、Next.js/TypeScript/Playwright 配置及部署模板。PDF.js 的两份必需模块以 gzip 资源及 Apache-2.0 许可证纳入 vendor/pdfjs，通过同源接口提供；下载时校验官方 npm 包 SHA-512，来源见 vendor/pdfjs/NOTICE.md。
