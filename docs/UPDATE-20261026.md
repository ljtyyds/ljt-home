# 2026-10-26 统一整理与管理员助手

## 使用方式

- 管理员在AI 助手聊天框发送一个 HTTP/HTTPS 链接，可自动识别为关注网站或行业资讯，生成可编辑草稿卡片。检查保存位置、分类和摘要后保存；新记录默认私有草稿。
- 已收藏的链接先按规范化网址精确匹配，卡片支持应用到原记录，继续校验记录版本，避免重复新增或覆盖其他编辑。
- 选择「读取网页并回答」可根据指定公开网址提问；可复用已保存正文。此功能读取指定链接，未接入关键词全网搜索或独立搜索 API。
- 聊天框的「补充正文」与新增表单的「补充正文」最多接受50000字符。有效正文优先使用，不再重复抓取；发送给模型时按长度截取，长文仍建议分主题整理。
- 新增网站、资讯的AI辅助分类与聊天整理、列表批量分类使用同一套有效内容获取和分类服务。表单保留手动输入与保存。

## 微信公众号

- HTTP 200不等于读到文章。环境异常、验证码、访问限制等页面会被识别，内容不足时不调用模型、不把验证页保存成摘要。
- 可以补充真实标题摘要后做有限依据分类，或粘贴正常阅读到的正文后重试。界面会标明依据来源。
- 微信要求验证时，不能保证仅凭链接抓取原文。本版没有浏览器剪藏扩展或验证码自动处理。

## 管理员与读者

- 管理员可读取公开网页、检索自己的收藏、生成整理草稿并通过既有保存接口写入。
- 读者仅检索公开站内资料，不能使用外部读取、正文导入或保存操作。
- 网页读取继续限制公开地址、校验每次重定向、固定DNS、设置时间与大小预算；没有开放服务器命令、文件读取或配置修改工具。
- 自定义分类由服务器重新校验；模型输出只作为建议，实际保存以接口返回为准。批量分类保留事务和撤销，内容不足的记录会跳过。

## 验证和发布

- 33项后端测试与8条浏览器流程，包含管理员/读者隔离、微信降级、统一分类、精确URL、保存刷新和桌面/手机缩放。
- 模型使用本地协议夹具测试，未调用真实付费API；云端仅做健康和权限检查。
- 保留环境文件、依赖、锁文件、构建与测试配置、部署模板、SSH及systemd配置。使用新发布目录构建、校验、备份后切换，保留上一版本。
- GitHub与ECS由本次授权发布同步；未增加自动部署工作流。
