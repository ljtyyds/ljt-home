# 论文库与 AI 导入

后续已扩展本地文件与论文名检索，并移除页面上重复的入口；当前使用步骤和边界见 [文件与论文名导入说明](UPDATE-20261027-PAPER-FILES.md)。

论文库位于“行业前沿”下。读者可以浏览、搜索论文；新增、导入、编辑、置顶与删除仅对管理员开放。网站、资讯、备忘录和待办的现有权限保持不变。

## 显示与编辑

- 标题、按顺序列出的作者、出版期刊／会议、出版年份、大致领域、中文摘要。
- SCI 分区（区分 JCR 与中科院口径）、CCF A/B/C 等级、期刊影响因子，以及各指标自己的年度、来源链接和依据原句。
- 正式出版年份与预印本记录年份分别标注；不把页面更新时间、收录时间或录用时间当成出版年份。
- 会议没有期刊影响因子；预印本不自动关联正式期刊／会议等级。无法确认的信息显示“未核实”，而不是推断它未被收录。
- 可以按标题、作者、DOI、领域、出版年份、标签搜索，并使用现有自定义分类筛选。

## AI 一键导入

1. 管理员进入论文库，点击“AI 一键导入”或“新增论文”。
2. 粘贴 DOI、DOI 链接、arXiv 摘要／PDF 链接或普通论文网页链接。
3. 点击“AI 一键导入”，生成可编辑草稿。Crossref DOI 元数据、arXiv 元数据优先于模型推断；模型整理领域、分类和中文摘要。
4. 网页不可读取时，可导入论文首页／摘要截图，或粘贴补充内容，再次导入。图片支持与现有助手相同的 PNG/JPEG/WebP 格式及大小限制。
5. 核对出版信息和指标，点击“保存论文”。导入本身不写库，保存后的论文对读者可见。

DOI 大小写、doi.org 与 dx.doi.org 的等价链接，以及同一 arXiv 编号的不同版本／PDF 链接会去重。再次导入已有论文时提示更新原记录，并使用版本号防止覆盖他人的新编辑。

## 指标的实际边界

Crossref/arXiv 不提供完整的最新 JCR／中科院分区、CCF 目录和影响因子数据，本次没有接入付费指标数据库，也没有更换现有模型、API 地址或密钥。AI 仅提取本次网页、截图或补充资料中带年度与来源的指标；无证据则留空，有证据也显示“待核实”。手动录入保留对应来源和年度。模型记忆不作为最新指标来源。

截图只提供可见内容，不代表已读取完整论文。原始图片不作为公开附件保存，图片分析仍通过现有模型 API 进行；长文、付费墙和验证码页面不能保证自动读取。当前不提供 PDF 文件上传解析，arXiv PDF 链接会转换到对应元数据记录。

## 配置、数据与验证

- 新增记录类型复用现有 SQLite entries JSON，不需要数据库表结构迁移，不改写已有记录。
- 保留环境文件、依赖与锁文件、Next.js/TypeScript/Playwright 配置及全部部署模板。
- 后端使用隔离数据库验证元数据一致性、出版年份、指标证据、去重、权限、并发编辑与截图流程。
- 浏览器通过隔离账号与模拟模型验证导入草稿、显式保存、读者只读、来源和年份展示、手机 120% 缩放及失败后保留输入。
- GitHub 提交后按现有方式备份、创建新发布目录并切换 ECS，校验原有数据与配置不变；没有新增自动部署配置。
