# 图片助手与统一可见

## 内容展示

- 关注网站和行业前沿统一对读者可见；新增、编辑和聊天保存均按同一规则处理。移除可见范围、发布状态、对应筛选和资讯发布日期展示/输入。
- 兼容旧记录：读取时规范化旧的私有/草稿标记，无需批量改写数据库；正常保存时写入统一公开状态。保留历史备份以便回退。
- 个人备忘录与待办仍只对管理员可见，所有写入仍需管理员登录。

## 自然语言聊天

- 移除聊天模式选择框和独立补充正文区域。直接输入“读取这个网页”“帮我分类”，或在同一个输入框粘贴“链接＋正文”。模型通过受校验的意图结果选择读取、分析或分类，服务端控制实际权限。
- 需要原文时可直接粘贴正文，或上传截图后说明“根据这张图继续分类”。在待补内容状态只发送图片时，会自动生成继续分类的提示词。
- 仍保留草稿预览、编辑和保存按钮，AI不会把仅生成建议说成已保存；保存后的文字内容对读者可见。

## 图片输入与分析

- 支持选择文件、粘贴截图；聊天还支持拖入图片。网站/资讯的AI辅助分类也可导入图片。
- 每次最多3张。原文件支持PNG/JPEG/WebP、单张不超过12MB；浏览器会缩放至最长边2400像素并压缩，每张上传数据不超过1500000字节。
- 不支持SVG、HEIC或动图。长截图建议分段，保持标题和关键正文清晰。
- 原始图片只用于当前会话请求，不写入收藏数据库或公开附件。保存记录时仅保存识别出的文字、摘要和分类；刷新或清空对话会清除会话图片。
- 当前调用模型需支持Chat Completions的image_url多模态输入。现有火山方舟DeepSeek-V4.1-Flash官方文档列出图片理解能力，本次保留原API地址、模型和密钥。
- 遇到不支持视觉、接口拒绝或识别失败，明确提示并保留输入和图片；不会生成假的识别结果或自动保存。
- 模型依据截图可见内容，不能补齐截图以外的完整文章。公众号验证页仍不能保证自动读取，截图提供了可替代的内容依据。

## 验证与发布

- 使用隔离数据和本地协议夹具测试自然语言意图、图片传输、识别后分类、读者只读及模型不兼容分支；未上传私人截图到真实模型。
- 保留环境文件、依赖/锁文件、Next.js/TypeScript/Playwright配置、部署模板、SSH和systemd配置。
- 新目录构建、备份后切换发布，核对原始记录和AI设置摘要；GitHub与ECS由本次授权同步，未新增自动部署工作流。
