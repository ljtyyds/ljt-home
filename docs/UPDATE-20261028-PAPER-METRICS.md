# 论文分区与等级补查

正式出处识别与等级查询是两个步骤。本次在论文导入识别出正式期刊或会议后，继续自动匹配 CCF；编辑表单提供“查询分区 / 等级”，已有记录无需重新读取 PDF。

## CCF 数据依据

使用中国计算机学会 2026 年第七版正式目录，包含 4 月 9 日勘误。事实数据从官方附件的 72 页表格提取，含 295 条期刊、386 条会议记录，每条保留目录类型、等级、名称及 PDF 页码。来源与文件 SHA-256 见 `server/ccfCatalog.ts`；正式发布说明：https://www.ccf.org.cn/Academic_Evaluation/By_category/ 。本地事实快照日期为 2026-10-28，后续目录发布需更新数据源，不能把此快照称为永久最新。

按全称或明确简称匹配，不使用任意包含关系。会议与期刊分开，Workshop、Findings、Companion 等不继承主会类别。显示的是会议/期刊目录类别，不能据此认定该记录一定属于目录考虑的 Full/Regular paper。2021 年论文匹配 2026 目录时，出版年份仍为 2021，CCF 显示“2026 · 目录年度”。ICML 位于官方 PDF 第 57 页，类别为 A；SCI 期刊分区和期刊影响因子对会议不适用。

## 期刊指标与边界

可提供公开可读的指标来源链接，或在补充内容中粘贴有权使用的期刊指标资料。需要期刊全称、来源链接、指标年度与依据原句；JCR 分区、中科院分区与影响因子分别验证，不把论文年份当作指标年份，不使用 SJR、CiteScore、五年影响因子替代 JIF。资料中的期刊、数值、年度或来源不一致时不应用，失败时保持原有输入。

Clarivate JCR 全量权威 API 需要付费授权，中科院分区数据也涉及授权访问。本次未新增授权账号或配置，因此不能保证所有期刊指标自动查全；没有资料时仍可查询 CCF 并保留现有指标，不凭记忆补造值。

查询接口仅管理员同源调用，返回可编辑草稿，显式保存才写入记录。查 CCF 不需要模型调用；期刊资料提取使用现有模型设置。新增的目录是版本化事实数据，不是环境或部署配置；未修改环境文件、依赖清单、锁文件、Next/TypeScript/Playwright/SSH 配置或部署模板。
