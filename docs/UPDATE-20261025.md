# 2026-10-25 功能更新

## 使用方式

1. 登录管理员，进入「设置 → 自定义分类」新增或重命名分类。分类会出现在筛选栏、编辑表单和AI分类选项中。
2. 删除分类时选择接收分类，已有内容只变更所属分类，不删除正文；「其他」为保留分类。名称最多30个字符，分类总数最多100个。
3. 在关注网站或行业前沿页面拖入一个浏览器链接，会打开预填网址的草稿。也可以在新增窗口拖入链接、粘贴网址或切换手动填写。
4. 点击「AI 识别并分类」，复用已有模型API设置。建议包括分类、标签、摘要；可读取时补充网页标题，最后点击保存才写入记录。
5. 无法读取需要登录、反爬或受限网页时，使用网址与已有文字辅助分类；无法调用模型或结果校验失败时保留草稿，可继续手动保存。处理期间编辑的内容不会被旧建议覆盖。
6. 右上角设置80%～120%的缩放。比例保存在当前浏览器的当前站点，刷新与同浏览器新页面保持；切换浏览器、域名或端口时分别保存。

## 权限与数据

- 分类新增、重命名、删除和草稿AI分类均在服务端校验管理员身份与请求来源。
- 删除分类转移关联内容并提高记录版本号，避免旧编辑覆盖新分类；已删除的历史分类不能通过AI撤销恢复。
- 页面缩放不修改服务器配置。模型密钥、管理员账号与现有收藏继续使用原数据目录。
- 保留原环境文件、Next.js/TypeScript/Playwright配置、依赖版本与锁文件、部署模板和systemd/SSH配置。
